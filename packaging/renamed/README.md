# rocketwright is now PhoneSimulator

This project drives iOS Simulators, real iPhones and iPads, Android devices and macOS apps for AI agents. From 3.13 it
is published as [`phonesimulator`](https://pypi.org/project/phonesimulator/):

```sh
uv tool install phonesimulator
```

Installing `rocketwright` 3.12.2 installs `phonesimulator` and nothing else. The command is `phonesimulator`
(`simtrail` still works); an MCP client configured with `rocketwright mcp` is changed to `phonesimulator mcp`.

The name Rocketwright now belongs to the browser tool, on npm: <https://www.npmjs.com/package/rocketwright>.

Source: <https://github.com/Soflutionltd/phonesimulator>
